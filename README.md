# Lab 2: Hierarchical Arithmetical Blocks

## List of Exercises

### 2.1.1 Carry Select Block
- **Description**: Implementation of a **Carry Select Block**, a hierarchical module that performs addition by selecting precomputed sums based on carry inputs.

### 2.1.2 Sum Generator
- **Description**: Design of a **Sum Generator** module, built using multiple Carry Select Blocks to efficiently compute the sum of input values.

### 2.1.3 Carry Generator
- **Description**: Implementation of a **Carry Generator** module using a sparse tree structure, which computes propagate and generate signals for carry lookahead.

### 2.1.4 Complete P4 Adder
- **Description**: Assembly of the **Complete P4 Adder**, combining the Sum Generator and Carry Generator modules to form a full adder structure.

### 2.1.5 Synthesis of the P4 Adder
- **Description**: Synthesis of the **P4 Adder** module to evaluate its structure, timing, and area characteristics.

### 2.2.1 Design of Booth's Multiplier
- **Description**: Implementation of a **32-bit parallel multiplier** using **Booth's algorithm**, which optimizes multiplication by encoding input values.

### 2.2.2 Synthesis of Booth's Multiplier
- **Description**: Synthesis of the **Booth Multiplier** module to analyze its structure, timing, and area for different bit-width implementations.
